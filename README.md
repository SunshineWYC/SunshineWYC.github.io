# Yongchang Wu (武永昌)

Personal academic homepage of Yongchang Wu, a Ph.D. student in the LEVIR Group at Beihang University.

Website: https://sunshinewyc.github.io/

## Editing content

- Profile and contact details: `_config.yml`
- Introduction: `_pages/includes/intro.md`
- News: `_pages/includes/news.md`
- Publications: `_pages/includes/pub.md`
- Honors and awards: `_pages/includes/honers.md`
- Education: `_pages/includes/others.md`
- Navigation: `_data/navigation.yml`
- Images: `images/`

The original template layout is preserved. Academic Service and its navigation entry are currently hidden.

## Deployment

GitHub Pages publishes the repository root from the `main` branch. Changes pushed to `main` trigger a new build and deployment.
The repository contains the homepage source, template code, and images used by this site. Local preview tools and unused template content are kept out of the repository.
